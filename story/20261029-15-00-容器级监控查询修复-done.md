# 容器级监控查询修复

## 背景
Docker 和 cri-dockerd 环境下 kubelet 容器指标缺少标签，KubeSphere 无法查询容器 CPU 和内存。

## 目标
恢复容器级 CPU、内存即时值和历史曲线。

## 范围
修改 ks-apiserver 的容器级查询，验证并部署修复版本。

## 非目标
更改容器运行时、修复 kubelet 原始指标标签或其他监控指标。

## 关键设计
保留原有查询，在缺失指标时按 Docker cgroup 容器 ID 与 kube-state-metrics 容器信息关联；按容器优先选择原有结果，避免重复计算。

## 验收标准
容器级 CPU 和内存查询与实际容器相符，原有标签完整的容器不重复计算；部署失败可恢复备份镜像。
